# `adapter-psm/src/main/java/hu/blackbelt/judo/meta/expression/adapters/psm` — the PSM binding of the expression `ModelAdapter` SPI: type/namespace resolution over PSM `NamespaceElement`s, the PSM measure provider, and the EVL validation entry point

| File | Purpose |
|---|---|
| `ExpressionValidatorOnPsm.java` | EVL entry point for validating an `ExpressionModel` against a `PsmModel`. Exports static `validateExpressionOnPsm(Logger, PsmModel, ExpressionModel)` and the overload taking `Collection<String> expectedErrors, expectedWarnings`. Delegates to `ExpressionValidator.validateExpression`, constructing `new PsmModelAdapter(psmModel.getResourceSet(), psmModel.getResourceSet())` and registering the SAME PSM resource under both epsilon model names `PSM` and `MEASURES` — PSM keeps measures inside the PSM resource, unlike ASM where measures live in a separate resource. Throws `ExpressionValidationException` when actual diagnostics differ from the expected sets. Java/Zeta validation is NOT reachable here; use `ExpressionZetaValidator` from the test module. |
| `PsmMeasureProvider.java` | Implements `MeasureProvider<Measure, Unit>` over PSM `hu.blackbelt.judo.meta.psm.measure` classifiers, scanning `resourceSet.getAllContents()` in parallel per lookup (no cache — cost is linear in model size per call). Exports `getMeasures`, `getUnits`, `getMeasure(namespace, name)`, `getMeasureNamespace`, `getUnitByNameOrSymbol`, `getBaseMeasures`, `isBaseMeasure`, `isDurationSupportingAddition`, `setMeasureChangeHandler`. Namespace FQ names are built by walking `PsmUtils.getNamespaceOfPackage` and joining with `::`. `isBaseMeasure` is `!(measure instanceof DerivedMeasure)`; `getBaseMeasures` folds `DerivedMeasure.terms` exponents and drops any measure whose summed exponent reaches 0. `getUnitByNameOrSymbol` with an absent `Measure` searches globally and throws `IllegalStateException("Ambiguous unit symbol…")` when two measures share a symbol. `isDurationSupportingAddition` is true only for `DurationUnit` whose `unitType` is one of `MILLISECOND, SECOND, MINUTE, HOUR, DAY, WEEK` — `MONTH`/`YEAR` are excluded because calendar length varies. `setMeasureChangeHandler` attaches an `EContentAdapter` to the resource set and never detaches it; adapters accumulate if called repeatedly. |
| `PsmModelAdapter.java` | Binds the generic expression `ModelAdapter` SPI to PSM classifiers; splits the entity side (`EntityType`/`Attribute`/`Relation`) from the exposed side (`TransferObjectType`/`TransferAttribute`/`TransferObjectRelation`), rewrites `.` namespaces to PSM `::`, and bridges measures through `PsmMeasureProvider`. → see `PsmModelAdapter.AGENTS.md` |
